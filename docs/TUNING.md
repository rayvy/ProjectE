# ProjectE — параметры для твика

Все параметры видны и крутятся вживую в панели (F1) прямо во время игры.
Порядок в этом файле = порядок, в котором их стоит крутить.

Управление: `WASD` — движение, `Shift` — бег, `Ctrl` — медленный шаг,
мышь — камера, `Esc` — освободить курсор.
`F1` панель · `F2` гизмо · `F3` следы · `F4` авто-тест · `R` респавн.

---

## 0. Телосложение (BUILD)

Пропорции живут в `RigDef`. Сырые замеры с ARP-рига лежат в `src_*` и никогда
не читаются напрямую — `rebuild()` пересчитывает из них рабочие размеры с
учётом масштабов. Поэтому другой персонаж = четыре числа, кода менять не надо.

| Параметр | Деф | Что делает |
|---|---|---|
| `scale` | 1.0 | Общий размер. 0.7 → 1.19 м, 1.35 → 2.30 м. |
| `leg_scale` | 1.0 | Только ноги. **Ноги задают высоту таза** — удлинил ноги, поднялось всё тело. |
| `torso_scale` | 1.0 | Только позвоночник + шея + голова. Длинный торс на тех же ногах. |
| `arm_scale` | 1.0 | Только руки. |
| `width_scale` | 1.0 | Ширина таза и плеч, независимо от роста. |
| `stand_reserve` | **0.990** | Какая доля ноги остаётся выпрямленной в покое. **Это и было «на корточках».** Вынос колена вперёд нелинеен у предела: 0.945 → 15 см (настоящий присед), 0.97 → 11 см, 0.99 → 3.4 см. Запас для конверта досягаемости даёт **присед таза** (`crouch_base`), а не согнутые колени в покое — поэтому значение может стоять почти у 1.0. 0.96 — настороженная стойка, 0.92 — боевая на полусогнутых. |

> Важно: должно выполняться `stand_reserve < soft_reach × max_reach`, иначе
> персонаж стоит с постоянно включённым клэмпом и висит в паре миллиметров над
> полом. Сейчас: 0.990 < 0.998 × 0.9995 = 0.9975. ✔

Из кода: `rig.set_total_height(1.60)` — подогнать под нужный рост, сохранив
пропорции. После любого изменения — `character.rebuild_rig()` (слайдеры в
панели делают это сами). Пересобирается всё: планировщик, манекен и физическая
капсула.

**Всё остальное масштабируется само.** Метровые параметры (`max_step`,
`trigger_error`, `step_apex`, `crouch_base`, `bob_amount`…) записаны для
эталонного рига и умножаются на `sz = leg_len / 0.9056` в точке применения.
Каденс идёт по числу Фруда (нога — маятник): частота ∝ 1/√L, длина шага ∝ L.
Проверено: 1.19 м → 3.24 шага/с, 1.70 м → 2.42, 2.30 м → 1.90, при этом
длина шага в длинах ноги держится 1.12–1.25 у всех трёх.

Единственное, что **не** масштабируется намеренно — `speed_walk` / `speed_jog`:
это геймдизайн, а не анатомия. Хочешь, чтобы мелкий не семенил как ускоренный —
умножь их на √scale вручную.

## 1. Вектор движения (GTA / RDR)

Сырой инпут **никогда** не идёт в скорость напрямую. Цепочка:

```
стик/WASD → сглаживание (input_lag)
          → INTENT-вектор (лимит поворота intent_turn_*)
          → фейсинг тела   (лимит поворота facing_turn_*)
          → скорость вдоль фейсинга (align_penalty, strafe_allowance)
```

Две задержки подряд и дают вес: стик ведёт, интент догоняет, тело догоняет
интент, ноги догоняют тело. Именно это убирает «шпагат на поворотах».

| Параметр | Деф | Что делает | Куда крутить |
|---|---|---|---|
| `input_lag` | 0.10 | Полупериод сглаживания сырого инпута, сек. | 0.15–0.20 — тяжелее, RDR. 0.04 — резко, аркада. |
| `intent_turn_idle` | 9.0 | Скорость поворота вектора намерения на месте, рад/с. | Меньше = тело «думает» дольше. |
| `intent_turn_top` | 2.4 | То же на скорости бега. | **Главный радиус разворота.** 1.5 — RDR-дуга, 4.0 — резвее. |
| `facing_turn_idle` | 8.0 | Скорость доворота корпуса на месте. | Ниже `intent_turn_idle` → корпус отстаёт. |
| `facing_turn_top` | 2.6 | Доворот корпуса на бегу. | Держи ≈ `intent_turn_top`. |
| `align_penalty` | 0.85 | Насколько рассинхрон «куда смотрю / куда хочу» режет скорость. | 1.0 = вообще не разгонишься боком. |
| `strafe_allowance` | 0.10 | Доля боковой скорости. | 0.0 = чистый GTA (только вперёд). 0.3 — можно поднырнуть вбок. |
| `turn_speed_penalty` | 0.55 | Насколько крутой поворот сбрасывает скорость. | Выше → перед резким поворотом обязан притормозить (RDR). |
| `pivot_brake` | 0.15 | Остаток тяги при развороте на 180°. | 0.0 = полная остановка и разворот на месте. |
| `accel` / `brake` | 7.5 / 9.0 | Разгон и торможение, м/с². | Ниже = тяжелее, инерционнее. |

## 2. Лимиты ног (защита от разрыва)

Три уровня, работают вместе. Гарантия: **лодыжка физически не может уйти от
бедра дальше `leg_len * max_reach`** — стопа никогда не отрывается от голени.

1. **Планировщик** не ставит цель дальше, чем нога реально дотянется
   (`step_radius()` считается из текущего допустимого приседа).
2. **Луч в землю** всегда находит настоящую поверхность, а потом результат
   сверяется с конвертом досягаемости (с запасом 5 см на то, что таз ещё
   доседает, пока стопа в воздухе). Нет твёрдой поверхности в пределах
   допустимого падения таза + длины ноги → **всё, лимит**: стопа зависает на
   границе досягаемости (гизмо краснеет).
3. **Мягкий клэмп** в позе: при подходе к лимиту стопа плавно «отлипает» от
   земли за несколько сантиметров, а не дёргается рывком на границе.

| Параметр | Деф | Что делает |
|---|---|---|
| `max_reach` | 0.9995 | Жёсткий предел: доля длины ноги, дальше — никогда. Держи у 1.0: это анатомический потолок, а не рабочая поза. Поза покоя задаётся `stand_reserve`, а запас — приседом таза. |
| `soft_reach` | 0.998 | С какой доли лимита начинается плавное отлипание. **Обязано быть выше `stand_reserve`**, иначе клэмп включён всегда, даже стоя. |
| `plan_reach` | 0.88 | Насколько глубоко внутри конверта планировщик разрешает себе целиться. |
| `max_step` | 0.62 | Абсолютный потолок выноса стопы от таза, м. |
| `crouch_base` | 0.085 | На сколько таз готов присесть, чтобы шаг дотянулся, м. |
| `crouch_per_speed` | 0.045 | Добавка к приседу на каждый м/с. Бег требует сильнее согнутого колена. |
| `knee_lock` | 1.0 | **1.0 = коленные чашки строго туда, куда смотрит тело.** 0.0 = колено ведёт по направлению шага. |
| `knee_out` | 0.20 | Развал колена наружу. |

Проверить: `F4` — авто-тест (спринт, разворот на 180°, диагональный срез,
стоп) печатает в консоль отчёт. `max_stretch_ratio` **должен быть ≤ 1.0**.
Текущий результат: `1.0` при 2600 кадрах жёсткого маневрирования.

Индикаторы в панели:
* `hanging (no ground)` — под стопой нет опоры в пределах досягаемости, висит.
* `reach clamp` — мягкий лимит работает прямо сейчас.
* Гизмо стопы: зелёный — опора, оранжевый — мах, **жёлтый** — клэмп, **красный** — висит.
* Линия бедро→лодыжка красится по натяжению ноги.

## 3. Планирование шага

Цель стопы = эвристика Райберта: `p = бедро + v·T_опоры/2 + k·(v − v_желаемая)`.
Первый член держит стопу под телом всю фазу опоры, второй — ловит баланс при
смене скорости (старт, стоп, толчок).

| Параметр | Деф | Что делает |
|---|---|---|
| `cadence_per_speed` | 0.92 | Шагов/с на каждый м/с. 1.65 м/с → 2.4 шага/с (человеческая норма ~2.2). |
| `duty_walk` | 0.68 | Доля опоры в цикле. <0.5 → появляется фаза полёта (бег). |
| `prediction` | 1.0 | Вес предсказания по скорости. 0 → стопа ставится под таз, ноги отстают. |
| `balance_gain` | 0.36 | Вес балансного члена. Выше → агрессивнее ловит себя при рывках. |
| `trigger_error` | 0.30 | На сколько стопа может уехать от идеала, прежде чем шагнуть вне расписания, м. |
| `step_apex` | 0.085 | Высота подъёма стопы в махе, м. |
| `heel_strike` / `toe_off` | 0.20 / −0.44 | Угол носка вверх при постановке пятки / подъём пятки при отталкивании, рад. Точка вращения переключается между пяткой и носком автоматически. |
| `ground_align` | 0.85 | Насколько стопа ложится по нормали склона. |

## 4. Корпус

Всё считается из **реального положения стоп**, а не из синуса по таймеру.

| Параметр | Деф | Что делает |
|---|---|---|
| `bob_amount` | 0.030 | Просадка таза в двухопорной фазе, м. Реальная вертикальная качка человека 4–5 см. |
| `lateral_shift` | 0.42 | Насколько таз наезжает на опорную ногу. |
| `hip_drop` | 0.087 | Завал таза в сторону маховой ноги (Тренделенбург), рад. |
| `pelvis_yaw_gain` | 0.30 | Разворот таза к ведущей ноге. |
| `chest_counter` | 0.85 | Контр-вращение груди против таза. |
| `lean_accel` | 0.055 | Наклон вперёд на каждый м/с² ускорения. |
| `bank_gain` | 0.85 | Завал в поворот (доля настоящего угла крена `atan(v·ω/g)`). |
